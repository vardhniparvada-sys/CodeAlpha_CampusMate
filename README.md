🎓 CampusMate – Smart College Assistant

Project Overview

CampusMate is an NLP-based FAQ chatbot designed to help college students get answers to frequently asked college-related questions.

Features

- College FAQ chatbot
- NLP-based question matching
- TF-IDF vectorization
- Cosine Similarity for matching questions
- Interactive Streamlit interface

Technologies Used

- Python
- Streamlit
- TF-IDF
- Cosine Similarity

Installation

pip install -r requirements.txt

Run Application

streamlit run app.py
